### 🚀 Featured Project

#### 📚 [AI Bookstore Assistant & Vision Concierge](https://github.com/HasnanMAhmad/AI-BOOKSTORE-ASSISTANT)
*A mobile-ready multimodal AI web application that identifies physical book covers and provides in-store literary consultations.*

- **Multi-Layer Recognition Pipeline**: Implemented a 4-layer vision system (EXIF orientation auto-transpose, structured cloud metadata extraction, RapidFuzz token matching, and visual verification) achieving 95%+ identification accuracy under real-world conditions (glare, hand-held tilt, and alternate covers).
- **Sub-Millisecond Cache**: Built an MD5 image fingerprinting system in SQLite delivering **0.001-second** repeat query responses with zero server lag.
- **Guardrailed Literary Agent**: Integrated Google Gemini with strict spoiler-prevention prompts, allowing customers to query pacing, tone, and reading chronology without spoiling plot twists.
- **Secure Architecture**: Designed an authenticated Staff & Admin Portal isolating credentials and catalog ingestion from the public client interface.
